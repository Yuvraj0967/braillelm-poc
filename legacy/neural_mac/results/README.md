# Measured results and predictions

Every `eval_*.json` file is the output of `code/eval.py` on a saved local
checkpoint. The corresponding `*_predictions.jsonl` file records each braille
input, English reference, and generated English hypothesis. These are raw
artifacts, not manually corrected examples.

The selected Qwen checkpoint is `qwen_bkft_continue4000/step4000`. Its
`eval_qwen_continue4000_plain.json` run used greedy decoding; the
`eval_qwen_continue4000_beam4_plain.json` run used four beams on the same
200-sentence plain development pilot. The
`eval_qwen_continue4000_beam4_extended_pilot.json` run used four beams on a
different 199-sentence development pilot. Files beginning `eval_scaled`,
`eval_aug`, `eval_baseline`, `eval_random`, and `eval_bkft` refer to smaller
SmolLM2 comparisons; their model weights are not part of the selected Qwen
release.

The 399-sentence locked final test was evaluated after checkpoint and beam
selection. `eval_qwen_final_locked_beam4.json` reports **216/399 (54.1%)**
strict exact, sacreBLEU 89.16, and mean CER 0.0231. Its predictions file
contains all 399 hypotheses. `final_independent_audit.json` was generated by
`../code/audit_final.py` and verifies row order, metrics, and the
training-unseen-word subgroup.

Check any exact-match claim directly:

```python

rows = [json.loads(s) for s in open(
    'results/eval_qwen_continue4000_beam4_plain_predictions.jsonl')]
```
